# VISION: The Ultimate Open-Source Marble Platformer

## Ultimate Goal
To transform Neverball from a classic arcade game into the definitive, ultimate open-source marble physics platformer. We aim to achieve complete feature parity with legendary commercial titles like Super Monkey Ball (1, 2, Deluxe, Banana Blitz/Mania) and Marble Blast, while preserving the open-source legacy and moddability of the original Neverball engine.

## Core Foundational Concepts
1. **Precision Physics First:** The core loop relies on tight, deterministic physics. Tilt control must be instantaneous, satisfying, and deeply mastered.
2. **Infinite Replayability via Content Generation:** Empower the community with robust in-game tools (Tile-Based Level Editor) and native sharing to ensure an endless stream of user-generated content.
3. **The Ultimate Party Game:** Support extensive local and online multiplayer modes (14+ minigames) that bring friends together in chaotic physics-based competition.
4. **Persistent Progression:** Reward player mastery with a robust economy, achievements, and unlockables that create a satisfying "just one more run" loop.

## User Satisfaction Design
* Every feature must be visible, understandable, and deeply satisfying to interact with.
* UI should be clear, animated, and responsive.
* Errors and friction points (like complex level editing) should be smoothed over with intuitive, user-friendly abstractions.
